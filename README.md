1. Для чего нужен JavaScript?
Для добавления интерактивности и поведения веб-страниц.

2. Как подключить внешний файл script.js?
С помощью тега <script src="script.js"></script>.

3. Что такое DOM?
DOM — представление HTML-документа в виде объектов, с которыми JavaScript может работать.

4. Для чего нужен querySelector()?
Для поиска HTML-элемента по CSS-селектору.

5. Что такое событие click?
Это событие, возникающее при нажатии на элемент.

6. Что делает addEventListener()?
Назначает обработчик события элементу.

7. Зачем используется textContent?
Для чтения или изменения текстового содержимого элемента.

8. Почему сообщение появляется только после нажатия?
Потому что код изменения текста выполняется внутри обработчика события click.

9. Чем отличаются селекторы #buy и .product?
#buy ищет элемент по ID, а .product — по классу.

10. Что произойдёт, если указать несуществующий ID?
querySelector() вернёт null, и при попытке вызвать у него addEventListener() возникнет ошибка.
